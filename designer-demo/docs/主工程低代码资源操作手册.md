# 主工程低代码资源操作手册

> **目的**：一眼看清「改哪块功能 → 看哪个文件夹 → 跑哪条命令 → 产出什么 → 设计器怎么吃到」。  
> **适用范围**：OAB 主工程 + VS Code 插件设计器联调 / 发布。  
> **原则**：三类资源职责分离，**不要**再把 styles / completion 混进物料包。

## 1. 总览：三块资源，三条线

| 资源                                               | 主工程配置/源目录    | 构建命令                   | 成果物落点                                                         | 设计器如何拿到                                | 主工程运行态                                                       |
| -------------------------------------------------- | -------------------- | -------------------------- | ------------------------------------------------------------------ | --------------------------------------------- | ------------------------------------------------------------------ |
| **物料组件**                                       | `lowcode-materials/` | `build:designer-materials` | `dist/lowcode-materials/`（`bundle.json` + `*.js` + `runtime.js`） | URL / ZIP 导入 / 插件物料配置                 | 出码页用真实 `mp-*`/`mr-*`，不靠此包                               |
| **公共样式**                                       | `lowcode-styles/`    | `build:lowcode-styles`     | `src/lowcode/style/`（`styles.json` + css）                        | **插件读工作区注入** `TINY_STYLE_BUNDLE_URLS` | 出码页走主工程 Uno/主题，不靠此包                                  |
| **补全 + utils/stores/composables/appState/modal** | `lowcode-utils/`     | `build:lowcode-utils`      | `src/lowcode/utils/` + `common/extensions/`（含 helpers）          | 插件注入 completion；运行态 glob              | `this.utils` / `stores` / `composables` / `appState` / **`modal`** |

```text
                    ┌─────────────────────────────┐
                    │   OAB package.json scripts  │
                    └──────────────┬──────────────┘
           ┌───────────────────────┼───────────────────────┐
           ▼                       ▼                       ▼
   lowcode-materials        lowcode-styles           lowcode-utils
           │                       │                       │
           ▼                       ▼                       ▼
 dist/lowcode-materials/   src/lowcode/style/     src/lowcode/utils/
   bundle.json …            styles.json …          completion-utils.json
                                                   + extensions/utils.js
                                                   + extensions/stores.js
                                                   + extensions/composable-helpers.js
           │                       │                       │
           ▼                       ▼                       ▼
   设计器：物料面板          设计器：Class Name       设计器：this.utils.
   （URL / ZIP）             画布样式（插件注入）      this.stores. / this.composables.
                                                       │
                                                       ▼
                                                 主工程预览出码页
                                                 this.utils / stores / composables
```

**易混点（务必记住）**

1. `dist/lowcode-materials` **只放组件物料**，不再放 `styles.json` / `completion-utils.json`。
2. Style / Completion 在插件场景下 **不依赖** `VITE_STYLE_BUNDLE_URLS` / `VITE_COMPLETION_CONFIG_URL`（可注释）；靠工作区文件注入。
3. 历史 `http://localhost:3000/styles.json`（与物料同目录）**已废弃**；`:3000` 现在只管物料 `bundle.json`。
4. **`this.utils` ≠ composable**：utils 只来自 `@/utils`；主工程 composable 一律 **`this.composables.<key>`**。

## 2. 命令速查（对着 package.json 看这张表）

### 2.1 日常主命令（记住这 5 个就够）

| 命令                                    | 什么时候用                                                | 产出                                                               |
| --------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------ |
| **`pnpm run build:designer-materials`** | 改了组件 / manifest / entries / 画布桩                    | `dist/lowcode-materials/`                                          |
| **`pnpm run build:lowcode-styles`**     | 改了 Uno、token、safelist、公共类                         | `src/lowcode/style/`                                               |
| **`pnpm run build:lowcode-utils`**      | 改了 `@/utils`、`storeWhitelist`、**`composableHelpers`** | `src/lowcode/utils/` + `extensions/`                               |
| **`pnpm run lowcode`**                  | 不确定、或一次全刷                                        | 上面三个依次执行                                                   |
| **`pnpm run lowcode:release`**          | 要打**物料**版本包发布                                    | materials 构建 + `versionize` → `dist/lowcode-materials-releases/` |

`build:designer-assets` = `lowcode:release` 的别名。

### 2.2 按需命令（不常用，别和日常混）

| 命令                           | 何时用                                   |
| ------------------------------ | ---------------------------------------- |
| `extract:design-tokens`        | 只刷新画布 token，不想完整 vite 物料构建 |
| `extract:canvas-assets`        | 只同步画布图标/图片                      |
| `extract:base-overrides`       | 只刷新 Vant 覆盖变量                     |
| `extract:canvas-styles`        | 从源码重抽某组件画布 CSS                 |
| `generate:canvas-stub`         | 批量生成/更新画布桩                      |
| `versionize:lowcode-materials` | 已有 materials dist，只做版本目录拷贝    |

`build:designer-materials` 内部已会跑前三个 extract；日常完整构建不必再手动 extract。

### 2.3 场景 → 命令（决策树）

| 你想…                                                             | 跑                                                                 | 然后                                                      |
| ----------------------------------------------------------------- | ------------------------------------------------------------------ | --------------------------------------------------------- |
| 物料面板多一个组件 / bundle 更新                                  | `build:designer-materials`                                         | serve `:3000` 或 ZIP 导入；Reload Host                    |
| Class Name / 画布 utilities 变了                                  | `build:lowcode-styles`                                             | Reload Host（插件重读 `src/lowcode/style`）               |
| `this.utils.` / `this.stores.` / **`this.composables.`** 补全变了 | `build:lowcode-utils`                                              | Reload Host；出码预览重启 `pnpm dev`（若改了 extensions） |
| 新增 store 白名单                                                 | 改 `manifest.storeWhitelist` → `build:lowcode-utils`               | 同上                                                      |
| 新增 / 开关 composable                                            | 改 `manifest.composableHelpers` → `build:lowcode-utils`            | 同上                                                      |
| 发物料压缩包给别人导入                                            | `lowcode:release` 或 materials + 自行打包 `dist/lowcode-materials` | **不含** style/completion                                 |
| 全都刷一遍                                                        | `pnpm run lowcode`                                                 | Reload Host                                               |

## 3. 分块操作手册

### 3.1 物料组件（lowcode-materials）

| 项                 | 内容                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| **文件夹**         | `OAB/lowcode-materials/`（`manifest.json`、`entries/`、`canvas-stubs/`、`icons/`） |
| **命令**           | `pnpm run build:designer-materials`                                                |
| **成果物**         | `dist/lowcode-materials/bundle.json`、各 `mp-*.js` / chunk、`runtime.js`、`icons/` |
| **设计器**         | `VITE_MATERIAL_BUNDLE_URLS=http://localhost:3000/bundle.json`，或插件 AM 导入 ZIP  |
| **本地 serve**     | `npx serve dist/lowcode-materials -p 3000 --cors`                                  |
| **不要放进包里的** | `styles.json`、`completion-utils.json`、`stores.js`                                |

新增组件最小步骤：改 manifest + entry（+ 必要时 designer/stub）→ 构建 → 刷新物料源。细节见 [物料导入快速参考](./物料导入快速参考.md)。

### 3.2 公共样式（lowcode-styles）

| 项         | 内容                                                                  |
| ---------- | --------------------------------------------------------------------- |
| **文件夹** | `OAB/lowcode-styles/`（构建脚本、safelist 等）                        |
| **命令**   | `pnpm run build:lowcode-styles`                                       |
| **成果物** | `src/lowcode/style/styles.json`、`tokens.css`、`utilities.css`        |
| **设计器** | 插件注入工作区 style；**不必**配 `VITE_STYLE_BUNDLE_URLS`（插件路径） |
| **备选**   | 无插件时静态服务 `src/lowcode/style/`，再配 env URL                   |

### 3.3 补全 / utils / stores / composables / appState / modal（lowcode-utils）

| 项                    | 内容                                                                        |
| --------------------- | --------------------------------------------------------------------------- |
| **文件夹**            | `OAB/lowcode-utils/`（`manifest.json`、`scripts/`）                         |
| **命令**              | `pnpm run build:lowcode-utils`                                              |
| **成果物**            | `completion-utils.json`；`utils.js` / `stores.js` / helpers → `extensions/` |
| **store 白名单**      | `manifest.storeWhitelist` → `this.stores.<key>`                             |
| **composable 白名单** | `manifest.composableHelpers` → **`this.composables.<key>`**                 |
| **应用级 state**      | `manifest.appStateWhitelist` → **`this.appState.<key>`**（模块单例）        |
| **modal 白名单**      | `manifest.modalHelpers` → **`this.modal.<name>`**（函数桥）                 |

**挂载面（勿混）**

| Page JS              | 真源                | 说明                                 |
| -------------------- | ------------------- | ------------------------------------ |
| `this.utils.*`       | `@/utils`           | 纯工具函数                           |
| `this.stores.*`      | `storeWhitelist`    | Pinia 实例                           |
| `this.composables.*` | `composableHelpers` | 主工程 composable 页级实例           |
| `this.appState.*`    | `appStateWhitelist` | 应用壳模块单例（如 TabBar）          |
| `this.modal.*`       | `modalHelpers`      | OTP / PIN 等弹窗（非整包 `@/modal`） |

**composableHelpers（当前）**

| key         | composable     | Page JS                                                    |
| ----------- | -------------- | ---------------------------------------------------------- |
| `clipboard` | `useClipboard` | `this.composables.clipboard.copy(text)`（别名 `copyText`） |
| `countdown` | `useCountdown` | `this.composables.countdown.startCountdown('60')`          |

**appStateWhitelist（当前）**

| key          | 源                   | Page JS                                                  |
| ------------ | -------------------- | -------------------------------------------------------- |
| `mainTabBar` | `mainTabBarAppState` | `this.appState.mainTabBar.setVisible(false)` / `reset()` |

**modalHelpers（当前）**

| name           | Page JS                                                      |
| -------------- | ------------------------------------------------------------ |
| `showPinInput` | `await this.modal.showPinInput({ inputmode: '0' })`          |
| `showCheckOTP` | `await this.modal.showCheckOTP({ … })`（会发码，需真实参数） |

-   补全：`this.composables.` / `this.appState.` / `this.modal.`。
-   **不要**再用 `this.utils.copyText` / `this.countdown`（旧挂载已废弃）。
-   支付鉴权优先 **`this.utils.requestPayment`**，不默认挂 `showRequestAuth`。
-   关闭：`"enabled": false` 后 rebuild。细节见 composable / appState / **modal** 导入思路文档。

**验证补全是否注入**（设计器 Console）：

```js
!!window.TINY_COMPLETION_CONFIG;
window.TINY_COMPLETION_CONFIG?.namespaces?.stores?.members?.map(m => m.name);
window.TINY_COMPLETION_CONFIG?.namespaces?.composables?.members?.map(
    m => m.name
);
window.TINY_COMPLETION_CONFIG?.namespaces?.appState?.members?.map(m => m.name);
window.TINY_COMPLETION_CONFIG?.namespaces?.modal?.members?.map(m => m.name);
```

**验证运行态**（主工程出码页，示例）：

```js
typeof this.composables?.clipboard?.copy; // 'function'
typeof this.appState?.mainTabBar?.setVisible; // 'function'
typeof this.modal?.showPinInput; // 'function'
await this.modal.showPinInput({ inputmode: '0', title: 'Demo PIN' });
```

## 4. 设计器 env 变量怎么理解

| 变量                         | 现在插件联调 | 说明                               |
| ---------------------------- | ------------ | ---------------------------------- |
| `VITE_MATERIAL_BUNDLE_URLS`  | **常用**     | 指物料 `bundle.json`（如 `:3000`） |
| `VITE_STYLE_BUNDLE_URLS`     | 可注释       | 插件已注入工作区 styles            |
| `VITE_COMPLETION_CONFIG_URL` | 可注释       | 插件已注入工作区 completion-utils  |

无插件、纯浏览器跑设计器时，后两个 URL 才是主通道。

## 5. 发布清单（复制用）

### 5.1 只发物料

-   [ ] `pnpm run build:designer-materials`（或 `lowcode:release`）
-   [ ] 检查 `dist/lowcode-materials/bundle.json`
-   [ ] ZIP 整目录或配置静态 URL
-   [ ] 设计器导入 / 刷新物料源

### 5.2 只发样式（工作区交付）

-   [ ] `pnpm run build:lowcode-styles`
-   [ ] 确认 `src/lowcode/style/*` 已更新并提交/同步到使用方仓库
-   [ ] Reload Extension Host

### 5.3 只发补全 / store / composable / appState / modal

-   [ ] 改 `lowcode-utils/manifest.json`（如需要）
-   [ ] `pnpm run build:lowcode-utils`
-   [ ] 确认 `src/lowcode/utils/completion-utils.json` 与 `extensions/*.js`（含 `modal-helpers.js`）
-   [ ] Reload Host；主工程预览验证 `this.stores` / `utils` / `composables` / `appState` / **`modal`**

### 5.4 全量

-   [ ] `pnpm run lowcode`
-   [ ] 物料：serve 或 ZIP
-   [ ] Reload Host
-   [ ] 出码页 `pnpm dev` 抽测

## 6. 反模式（曾经跑偏的做法）

| 不要这样做                                                | 应该                                                 |
| --------------------------------------------------------- | ---------------------------------------------------- |
| 指望 `build:designer-materials` 顺带更新 completion       | 单独 `build:lowcode-utils`                           |
| 在 `dist/lowcode-materials` 里找 `styles.json`            | 看 `src/lowcode/style/`                              |
| 用 `:3000/styles.json` / 依赖未注释的 style env           | 插件工作区注入                                       |
| 手改 `extensions/utils.js` / `stores.js` / `*-helpers.js` | 改源 / manifest + rebuild                            |
| 业务手改出码 `views/*.vue`                                | 改 schema json 再出码                                |
| 以为物料 ZIP 会带上 store / composable 实现               | 运行态在主工程 `extensions`；补全在工作区 JSON       |
| 把 composable 再塞进 `this.utils` 或挂 `this.<key>` 一级  | 统一 **`this.composables.<key>`**                    |
| 默认把所有公共 composable 暴露给 Page JS                  | 多数用 http / stores / router / 物料替代             |
| 整包挂 `@/modal` 或默认暴露支付鉴权 modal                 | **`this.modal` 白名单**；支付走 **`requestPayment`** |
