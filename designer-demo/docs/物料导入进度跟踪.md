## 四、导入优先级建议

1. **高优先级**（页面骨架、常用）：mp-page、mp-block、mp-button
2. **中优先级**（表单与输入）：mp-dict-input、mp-textarea、mp-mobile-input、mp-multi-amt、mp-country-input、mp-bank-input、mp-city-input
3. **中优先级**（交互反馈）：mp-popup、mp-dialog、mp-result、mp-empty（已测）
4. **低优先级**（骨架、刷新等）：mr-refresher、mp-list-skeleton（mr-skeleton-text 已测）
