## 0. 总览（按类别看进度）

手写页常用能力与低代码挂载面对应关系：

```text
手写页常用能力
├─ @/utils ────────────────── this.utils        → 主线完成（剩清单/示例）
├─ @/stores ───────────────── this.stores       → 主线完成（三级补全可选）
├─ @/composables ──────────── this.composables  → 机制完成；白名单按需扩
├─ 平台内置 ───────────────── http / router / i18n → 基本完成；router 有小缺口
├─ 应用级 state（模块单例）── this.appState     → 主线完成（mainTabBar）；白名单按需扩
├─ @/modal ────────────────── this.modal        → 主线完成（PIN/OTP）；白名单按需扩
├─ @/services ─────────────── （可选只读）      → 未做（P2）
└─ shared/* 领域 ──────────── 不宜全局 this     → 跟业务模块 / 物料
```

| 类别 | 低代码挂载面 | 主线状态 | 一句话 |
|------|--------------|----------|--------|
| `@/utils` | `this.utils` | **主线完成** | 整包已导出；剩可发现性（清单/示例），不是接线 |
| `@/stores` | `this.stores` | **主线完成** | 公共 store 16 个已白名单；三级方法补全可选 |
| `@/composables` | `this.composables` | **框架完成，白名单少** | 统一挂载已定；目前仅 clipboard / countdown |
| 平台内置 | `this.http` / `router` / `i18n` | **基本完成，有小缺口** | http、`i18n(t)` 够用；router 目前主要补了 `goBack` |
| **应用级 state** | **`this.appState`** | **主线完成** | 机制 + `mainTabBar` 已落地；白名单按需扩 |
| `@/modal` | **`this.modal`** | **主线完成** | `showPinInput` / `showCheckOTP`；勿整包；支付鉴权仍走 `requestPayment` |
| `@/services` | （无） | **未做** | 可选只读 `getService` |
| `shared/*` 领域 | （无全局） | **刻意不做全局** | 跟业务模块/物料，不进全局 `this` |

**进度图例**：`[x]` 已完成 · `[~]` 部分完成 / 可选增强 · `[ ]` 未做 · `[-]` 明确不做（全局线）

## 1. `@/utils` → `this.utils`

| 项 | 说明 |
|----|------|
| **真源** | `src/utils/index.ts`（barrel） |
| **产物** | `build:lowcode-utils` → `extensions/utils.js` + `completion-utils.json` → `namespaces.utils` |
| **挂载** | `lowcode.js` → `this.utils`（与手写 `import { … } from '@/utils'` 同源） |

### 进度

- [x] 整包导出运行态
- [x] 设计器 `this.utils.` 二级补全
- [x] 与物料解耦（不进 `dist/lowcode-materials`）
- [~] Page JS「常用清单」文档与补全排序（toast / picker / payment / fd / currency…）
- [~] 文档标注慎用/禁用项（见下）

### 已覆盖能力（摘要，均在 `this.utils`）

| 子类 | 典型 API |
|------|----------|
| Dialog / Toast / Picker | `showToast`、`showLoading`、`hideLoading`、`showAlert`、`showConfirm`、`showPicker`、`showMultiplePicker`、`showActionSheet`… |
| 格式化 | `fd` / `fdate`、`currency` / `getCurrency`、`fr`、`to`、lodash 子集 |
| 支付鉴权（utils 层） | `requestPayment` |
| 存储 / 事件 | `commonStorage`、`commonUserStorage`、`eventBus` |
| 常量 | `RequestName`、`RouteName`、`OtpType`、`PasscodeType`、`MrPlatform`…（公共子集） |
| 文件 / 媒体 / 预览 | `getFileUrl`、`chooseImage`、`uploadFile`、预览相关 |
| 其它 | `http`（亦有 `this.http`）、`mrBox`、`isPlatform`、crypto re-export… |

### 慎用 / 不建议业务 Page JS 随意用

| API / 对象 | 原因 |
|------------|------|
| `mrBox` 全量 | 设备/支付/文件系统面过大 |
| `@mr/crypto` 全套 | 应走统一加密 / encrypt store |
| `popupQueue` / `registerWidget` | 启动与架构职责 |
| `setAuthToken` / `setUserNo` | 会话底层，禁止业务随意写 |

### 状态结论

**告一段落（接线完成）**。后续是体验与规范，不是再导出一套。

## 2. `@/stores` → `this.stores`

| 项 | 说明 |
|----|------|
| **真源** | `lowcode-utils/manifest.json` → `storeWhitelist` |
| **产物** | `stores.js` → `extensions/stores.js`；补全 `namespaces.stores` |
| **挂载** | `this.stores.<短名>`（实例，非 `useXxxStore()`） |

### 进度

- [x] 白名单单源 + 运行态挂载
- [x] `this.stores.` 二级补全
- [x] 公共 `src/stores` 全量 16 个进白名单并验证
- [~] 三级方法补全（可选；建议仅热点 store 手写 `members`，勿全量扫描）

### 当前白名单（16）

`transaction`、`local`、`user`、`dict`、`payment`、`app`、`constant`、`account`、`dir`、`theme`、`limit`、`banner`、`agreement`、`introduce`、`encrypt`、`secure`

> 以 manifest 为准；细节见 [主工程 store 导入思路](./主工程store导入思路.md)。

### 三级补全建议（未做，可选）

|--------|--------|--------------|
| P0 | `transaction` | `setTransResult`、`openResultPage` |
| P0 | `secure` / `encrypt` | PIN / 加密相关公开方法 |
| 暂缓 | `local` / `dict` | 表面过大，易噪声 |

### 状态结论

**告一段落（主线完成）**。三级补全是体验增强，非阻塞。

## 3. `@/composables` → `this.composables`

| 项 | 说明 |
|----|------|
| **真源** | `manifest.composableHelpers` |
| **产物** | `composable-helpers.js`；补全 `namespaces.composables` + `children` |
| **挂载** | **统一** `this.composables.<key>`（页级 `useXxx()` 一次）；已取消 `mount: utils \| page` |

### 进度

- [x] 统一挂载面与生成器 / 补全（含三级 `this.composables.countdown.`）
- [x] 第一批：`clipboard`（`useClipboard`）、`countdown`（`useCountdown`）
- [x] 专项文档：[主工程 composable 导入思路](./主工程composable导入思路.md)
- [ ] 按业务按需扩白名单（默认多数不导出）

### 当前白名单

| key | 源 | Page JS |
|-----|-----|---------|
| `clipboard` | `useClipboard` | `this.composables.clipboard.copy` / `copyText` |
| `countdown` | `useCountdown` | `this.composables.countdown.startCountdown` 等 |

### 准入规则（扩白名单前必看）

**默认不导出。** 仅当：Page JS 高频、且没有 `this.http` / `this.stores` / `this.router` / 物料等价写法时，才进 `composableHelpers`。

| 候选（未做） | 说明 | 建议 |
|--------------|------|------|
| `useQuery` / `useQueryMap` | 带 loading 请求封装 | 按需；也可用 `this.http` |
| `useKeyboard` | 键盘高度 | 表单页有需要再加 |
| `useMpRouter` | 导航 | 优先扩 `this.router`，不必重复挂 composable |
| 其它 VueUse / 窄场景 | — | 默认不导出 |

### 状态结论

**机制告一段落；白名单按需加。** 不是「composable 全导入完」。

## 8. 应用级 state（模块单例）→ `this.appState`

> **定位**：非 Pinia、模块顶层 `ref`/`readonly` + 受控写方法的**应用壳 / 跨页单例**。  
> 与 `this.stores` 并列：stores = 业务域状态；appState = 壳层或跨页轻量 UI 状态。  
> 专项文档：[主工程应用级 state 导入思路](./主工程应用级state导入思路.md)。

| 项 | 说明 |
|----|------|
| **挂载** | **`this.appState.<key>`** |
| **配置** | `manifest.appStateWhitelist` |
| **产物** | `app-state-helpers.js` → `extensions/`；补全 `namespaces.appState` |

### 当前白名单

| key | 源 | 常用 API |
|-----|-----|----------|
| `mainTabBar` | `mainTabBarAppState` | `setVisible` / `reset` / `visible` |

### 进度

- [x] manifest + 生成器 + `lowcode.js` 挂载
- [x] 补全 `namespaces.appState` + 关键字
- [x] 第一项 `mainTabBar` + demo（Show Pop 隐藏 / Show Dialog 恢复）
- [ ] 按需扩白名单（默认个位数）

### 状态结论

**主线完成（机制 + mainTabBar）**。扩员保持少而精。
