# 主工程低代码集成指南

> **适用范围**：将 TinyEngine 低代码能力接入 Vue3 + Vite 主工程（以 OAB 集成为例，参考原 mobilebanking 工程）。  
> **读者**：主工程开发、设计器/插件联调人员。  
> **关联文档**：[VSCode 集成](./VSCode-Integration.md)、[插件与设计器物料导入对接与排障](./插件与设计器物料导入对接与排障.md)、[物料导入快速参考](./物料导入快速参考.md)、主工程 `lowcode-materials/README.md`。

---

## 1. 背景：从「复制代码」到「可用」

初期做法是从 **mobilebanking** 向新主工程 **OAB** 复制 `lowcode-materials/`、`lowcode-styles/`、`lowcode-utils/`、`src/lowcode/` 及部分 Vite 配置。复制后会出现「设计器能编辑、主工程预览/出码不能跑」的情况。根因不是出码失败，而是**主工程运行时与构建链路未完整接通**。

典型演进与对应修复如下：

| 阶段 | 现象 | 根因 | 处理 |
|------|------|------|------|
| 1 | 设计器保存/出码后，访问 `#/lowcode/xxx` 白屏 | 主工程 **未注册低代码路由** | 新增 `src/router/lowcode.ts`，在 `src/router/index.ts` 合并 `lowcodeRoutes` |
| 2 | 控制台 `inject(I18nInjectionKey)` 为 undefined | 未 `provide` 完整 i18n 实例 | `src/main.ts` 中 `app.provide(I18nInjectionKey, i18n)` |
| 3 | `Cannot read properties of undefined (reading 'lowcode')` | 同上，或 `lowcode()` 未挂载 | `main.ts` 在 provide 前挂载 `(i18n as any).lowcode = lowcode`（**不要**在 `i18n/index.ts` 静态 import `lowcode.js`） |
| 4 | `Cannot access 'i18n' before initialization` | `i18n/index.ts` 静态 import `lowcode.js` → 循环依赖 | 仅在 `main.ts`：先 `import i18n`，再 `import lowcode` 并挂载 |
| 5 | `pnpm build:designer-materials` 失败 | Uno 扫描 `src/lowcode` 中 demo 页的 `@opentiny/*` | UnoCSS 排除 `src/lowcode/**`；删除 demo 页；**不必**安装 `@opentiny/*` |
| 6 | 物料构建缺 `~icons/...` | `vite.lowcode-materials.config.ts` 未配置 unplugin-icons | 对齐主工程 `build/icon.ts` 增加 Icons 插件 |
| 7 | Extension Host 仍打开旧工程 | F5 调试窗口的工作区不是新主工程 | **文件 → 打开文件夹** 选新主工程根目录 |

当前 OAB 上 **donations** 低代码页（如 `#/lowcode/lowcode-donations-list`）已可设计、出码、预览。

## 2. 架构与职责

```
┌─────────────────┐     AM 导入 ZIP      ┌──────────────────────────────┐
│ 主工程 (OAB)    │ ──────────────────► │ src/lowcode/assets/packages/ │
│ build 物料产物  │                      └──────────────────────────────┘
└────────┬────────┘                                    ▲
         │ pnpm build:designer-materials                 │ 静态服务 + 注入 URL
         ▼ dist/lowcode-materials/                      │
┌─────────────────┐     postMessage      ┌──────────────────────────────┐
│ designer-demo   │ ◄──────────────────► │ lowcode-kit VSCode 插件       │
│ (设计器, ~8090) │                      │ Extension Development Host    │
└─────────────────┘                      │ 必须打开【主工程根目录】       │
         │ 出码写入                        └──────────────────────────────┘
         ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ src/lowcode/modules/<业务>/routes/*.ts  +  views/*.vue  +  *.json      │
│ 主工程 dev：#/lowcode/lowcode-<path>  ← router/lowcode.ts 自动注册      │
└─────────────────────────────────────────────────────────────────────────┘
```

- **主工程**：产出物料包、承载出码页面、提供真实 `http`/stores/路由。
- **插件**：认 **当前工作区根目录**（不是 lowcode-kit 仓库本身）；AM 导入、静态服务、注入 `TINY_MATERIAL_BUNDLE_URLS`。
- **设计器**：消费插件注入的物料 URL；`developmentServerUrl` 指向 designer-demo 开发服务。

## 3. 从参考工程复制的内容（新主工程第一步）

从已跑通的主工程（如 mobilebanking / OAB）**整目录复制**到新高代码主工程根目录：

| 路径 | 说明 |
|------|------|
| `lowcode-materials/` | 物料 manifest、entries、canvas-stubs、构建脚本 |
| `lowcode-styles/` | UnoCSS 公共样式产物脚本 |
| `lowcode-utils/` | 出码 utils 扫描与 `completion-utils.json` |
| `vite.lowcode-materials.config.ts` | 物料 ESM 构建 |
| `vite.runtime.config.ts` | 画布 runtime（`runtime.js`） |
| `src/lowcode/` | 出码目录、common/config、i18n、stores、utils 等 |

复制后**必须**按本文第 4、5 节改主工程入口与路由，不能只复制目录。

**不建议默认复制**：

- mobilebanking 里设计器自带的 **demo 出码页**（如 `CreateVm`、`test2`、`airtime` 等 OpenTiny 示例）——与业务 `mp-*` 物料无关，且会引入无用依赖。
- `@opentiny/vue`、`@opentiny/vue-icon`（除非业务页面明确使用 Tiny 组件）。

## 4. 主工程必须新增 / 修改的文件

### 4.1 新增文件

| 文件 | 作用 |
|------|------|
| `src/router/lowcode.ts` | `import.meta.glob` 扫描 `src/lowcode/modules/**/routes/*.ts` 与 `views/**/*.vue`，注册 `lowcode.<module>.<name>` 路由 |
| `types/lowcode.d.ts` | 声明 `@/lowcode/common/config/lowcode` 模块类型，通过 `vue-tsc` |

`lowcode.ts` 逻辑与 mobilebanking 一致：路径形如 `module: 'lowcode'` + `path: 'lowcode-donations-list'` → URL **`/lowcode/lowcode-donations-list`**。

### 4.2 修改文件

| 文件 | 修改要点 |
|------|----------|
| `src/router/index.ts` | `import { lowcodeRoutes } from './lowcode'`；native 与 web 分支的 `children`（或顶层 routes）均合并 `...lowcodeRoutes` |
| `src/main.ts` | ① `import lowcode from '@/lowcode/common/config/lowcode'`（在 `import i18n` **之后**）② 挂载 `i18n.global.lowcode` / `i18n.lowcode` ③ `app.provide(I18nInjectionKey, i18n)`，且在 `app.use(plugins)` **之前** |
| `src/plugins/i18n.ts` | `import.meta.glob('@/lowcode/common/i18n/index.js')` 合并 `enUS` / `zhCN` |
| `src/i18n/index.ts` | **不要**静态 import `lowcode.js`（避免与 `@/utils` / composables 循环依赖） |
| `package.json` | 增加第 5 节脚本；物料构建所需 devDependency 已存在则不必重复 |
| `vite.lowcode-materials.config.ts` | 见 4.3；从参考工程复制后核对 Icons、UnoCSS content |
| `tsconfig.eslint.json` | `include` 增加 `lowcode-materials`、`lowcode-utils`（若 ESLint 检查这些目录） |
| `.eslintrc.cjs` | `ignorePatterns` 增加 `lowcode-materials/**`、`src/lowcode/**`（出码 JS 与生成代码免 lint） |
| `.husky/lintstagedrc.cjs` | 与团队规范一致；`extract-base-overrides.cjs` 生成 CSS 勿用 `//` 注释（Prettier 会失败） |

### 4.3 `vite.lowcode-materials.config.ts` 必要配置（推荐写入集成清单）

除从参考工程复制外，新主工程建议确认：

1. **unplugin-icons**：与主工程 `build/icon.ts` 一致，否则物料构建可能无法解析 `~icons/...`（如 account 相关 store 引用）。
2. **UnoCSS 扫描范围**（**强烈建议**，非可选最佳实践）：

```ts
Unocss({
    configFile: './uno.config.ts',
    content: {
        pipeline: {
            include: [
                'src/components/**/*.{vue,js,ts}',
                'src/layout/**/*.{vue,js,ts}',
                'src/shared/**/*.{vue,js,ts}',
                'lowcode-materials/**/*.{vue,js,ts}',
            ],
            exclude: ['src/lowcode/**'],
        },
    },
});
```

**原因**：`src/lowcode/**` 是**运行时出码页**，不参与「物料 ESM + mr-bank.css」构建；扫描它们会把无关页面卷入 Rollup，并可能因未声明依赖导致构建失败。

3. **alias（画布桩）**：`@/stores`、`@/utils`、`vue-router`、`vue-i18n` 指向 `lowcode-materials/canvas-stubs/`（与参考工程一致）。

## 5. `package.json` 脚本与依赖

### 5.1 建议增加的 scripts

```json
{
  "lowcode": "pnpm run build:designer-materials && pnpm run build:lowcode-styles",
  "lowcode:release": "pnpm run build:designer-materials && pnpm run build:lowcode-styles && pnpm run versionize:lowcode-materials",
  "build:designer-materials": "node lowcode-materials/scripts/extract-design-tokens.cjs && node lowcode-materials/scripts/extract-canvas-assets.cjs && node lowcode-materials/scripts/extract-base-overrides.cjs && vite build --config vite.lowcode-materials.config.ts && vite build --config vite.runtime.config.ts && node lowcode-materials/scripts/generate-bundle.cjs && node lowcode-utils/scripts/build.mjs",
  "build:lowcode-styles": "node --experimental-strip-types lowcode-styles/scripts/build.mjs",
  "build:lowcode-utils": "node lowcode-utils/scripts/build.mjs"
}
```

| 命令 | 用途 |
|------|------|
| `pnpm run build:designer-materials` | **联调前必跑**：产出 `dist/lowcode-materials/`（bundle、mp-*.js、mr-bank.css、runtime.js、completion-utils.json） |
| `pnpm run lowcode` | 物料 + 公共样式（设计器 Class Name / token） |
| `pnpm run lowcode:release` | 带版本目录的发布产物 |

### 5.2 依赖说明

| 依赖 | 是否必需 | 说明 |
|------|----------|------|
| 现有 Vue / Vant / `@mr/wise-core` / UnoCSS | 是 | 物料与主工程一致 |
| `unplugin-icons`（通常已有） | 物料构建需要 | 在 `vite.lowcode-materials.config.ts` 中启用 |
| `@opentiny/vue` / `@opentiny/vue-icon` | **否** | 仅 OpenTiny demo 页需要；业务低代码用 `mp-*` / `mr-*` |
| `@opentiny/unplugin-tiny-vue` | **否** | mobilebanking 主 vite 用于 Tiny 组件；OAB 未接则可不装 |

## 6. 集成步骤（推荐顺序）

### 步骤 A：主工程侧 — 目录与构建

1. 复制第 3 节目录与 `vite.*.config.ts` 到新主工程。
2. 合并 `package.json` scripts（第 5 节）。
3. 按第 4 节修改 `router`、`main.ts`、`plugins/i18n.ts`，新增 `types/lowcode.d.ts`。
4. 核对 `vite.lowcode-materials.config.ts`（Icons + UnoCSS exclude）。
5. 执行：

```bash
cd /path/to/主工程
pnpm install
pnpm run build:designer-materials
```

成功标志：`dist/lowcode-materials/bundle.json` 存在，控制台无 Rollup resolve 错误。

可选：

```bash
pnpm run lowcode          # 含公共样式
pnpm type-check           # 主工程类型检查
```

### 步骤 B：插件与设计器

1. 在 **lowcode-kit** 中 F5 启动 **Extension Development Host**。
2. 在该窗口 **文件 → 打开文件夹**，选择**新主工程根目录**（例如 `OAB`，不是 `lowcode-kit`、不是旧的 mobilebanking）。
3. 将 `dist/lowcode-materials` 打成 ZIP，通过插件 **AM 导入** 到 `src/lowcode/assets/packages/<id>/`（详见 [物料导入快速参考](./物料导入快速参考.md)）。
4. 启动 **designer-demo**（通常 `pnpm dev`，端口如 8090）；插件配置 `lowcode-designer.developmentServerUrl` 指向该地址。
5. 在设计器中编辑页面 → 保存 → 出码，确认写入 `src/lowcode/modules/<模块>/`。

### 步骤 C：主工程运行时验证

1. 主工程 `pnpm dev`（修改 `main.ts` / 路由后需**重启**）。
2. 浏览器访问出码路径，例如：

```
http://localhost:<port>/#/lowcode/lowcode-donations-list
```

### 步骤 D: 主工程开启本地物料供设计器验证

1. 运行命令，本地起服务，设计器通过主工程开启的服务，本地访问物料，不用用过ZIP导入。

```
npx serve dist/lowcode-materials -p 3000 --cors
```

## 8. 常见问题与处理

| 问题 | 可能原因 | 处理 |
|------|----------|------|
| `No match found for path "/lowcode/..."` | 未合并 `lowcodeRoutes` | 检查 `src/router/lowcode.ts` 与 `router/index.ts` |
| `inject(I18nInjectionKey)` not found | 未 `provide(i18n)` | 在 `main.ts` 中 `app.provide(I18nInjectionKey, i18n)` |
| `Cannot read 'lowcode'` | 未挂载 `lowcode()` | `main.ts` 中给 `i18n` / `i18n.global` 赋值 `lowcode` 导出函数 |
| `Cannot access 'i18n' before initialization` | `i18n/index.ts` 静态 import `lowcode.js` | 仅在 `main.ts` 引入并挂载 lowcode |
| `build:designer-materials` 无法解析 `@opentiny/vue-icon` | Uno 扫描了 `src/lowcode` 中的 demo 页 | UnoCSS `exclude: ['src/lowcode/**']`；删除 demo；勿加 OpenTiny 依赖 |
| 无法解析 `~icons/...` | 物料 vite 未配 Icons | 对齐 `vite.lowcode-materials.config.ts` 与 `build/icon.ts` |
| 设计器仍指向 mobilebanking | Extension Host 打开了错误文件夹 | 在同一 Host 窗口重新打开主工程根目录 |
| 预览有路由但组件红错 | 物料未构建或 AM 未导入 | 先 `build:designer-materials`，再 AM 导入 ZIP |
| `[intlify] key not found` | lowcode 文案未合并 | 确认 `plugins/i18n.ts` glob `@/lowcode/common/i18n/index.js` |
| pre-commit 失败（lowcode CSS） | 生成 CSS 含 `//` 注释 | `extract-base-overrides.cjs` 输出改用 `/* */` |
| 出码页 class 不生效 | 未构建 lowcode-styles | `pnpm run lowcode` 或 `build:lowcode-styles` |

## 9. 出码目录约定（与预览 URL 对应）

出码路由文件示例（`donations-listRoute.ts`）：

```ts
export default {
  module: 'lowcode',
  routes: [{
    name: 'donations-list',
    path: 'lowcode-donations-list',  // 勿 leading slash
    meta: { ktTitle: 'Donations' },
  }],
};
```

- **路由 name**：`lowcode.lowcode.donations-list`（`lowcode.${module}.${route.name}`）
- **浏览器 path**：`/lowcode/lowcode-donations-list`
- **预览 URL**：`#` + 上述 path

业务页面应使用 **`mp-*` / `mr-*`** 物料；避免在设计器保留 OpenTiny `tiny-*` demo，以免引入额外依赖与构建扫描问题。

## 10. 与 mobilebanking 的差异摘要

| 项 | mobilebanking | OAB（新主工程建议） |
|----|---------------|---------------------|
| 低代码路由 | 已接入 | 需新增 `router/lowcode.ts` |
| `main.ts` provide i18n | 有 | **必须**补上 |
| `lowcode()` 挂载位置 | 动态 import 于 i18n | **推荐**仅 `main.ts` 同步挂载 |
| OpenTiny 依赖 | 有（含 demo） | **可不装**（仅用 mp/mr 物料） |
| UnoCSS 物料构建 | 未显式 exclude lowcode | **建议** exclude `src/lowcode/**` |
| Web 布局 | 部分差异 | `lowcodeRoutes` 需并入 web `children` |
